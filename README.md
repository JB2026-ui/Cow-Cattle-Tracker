# Cow-Cattle-Tracker
A system that allows cattle farmers to electronically create records of their cattle.
Team - Jared Barnes
Paragraph - Building a Cattle Tracker mainly for Coes for Cattle farmers. Using this will allow them to have a digital database of their animals to help keep track of them. From being able to track breeding cycles and family trees to prevent inbreeding. Inspired to do this because my father always wanted to do his records digitally and has not had a moment to shift. This is being made in mind to be simple and easy to use.
